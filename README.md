 MadaEyes

 Site web touristique dédié à Madagascar

**MadaEyes** est un site web touristique conçu pour faire découvrir Madagascar, ses destinations, sa culture, ses paysages et ses richesses naturelles.

Le projet propose une interface moderne, responsive et facile à utiliser, permettant aux visiteurs d'explorer différentes régions et destinations de Madagascar.

---

 Objectifs du projet

L'objectif de **MadaEyes** est de :

* 🌍 Promouvoir les destinations touristiques de Madagascar
* 🏝️ Présenter les différentes régions et villes du pays
* 🦎 Mettre en valeur la faune et la flore malgaches
* 🎭 Faire découvrir la culture et les richesses de Madagascar
* 📱 Proposer une expérience adaptée aux ordinateurs et aux appareils mobiles
* 💻 Mettre en pratique les compétences en développement web

---

 Fonctionnalités

Le site comprend notamment :

*  Page d'accueil
 Présentation de Madagascar
*  Présentation de différentes destinations
*  Pages dédiées aux principales villes et régions
*  Galerie d'images
*  Section forum
*  Formulaire d'inscription
*  Interface responsive
*  Animations avec AOS
*  Adaptation aux smartphones, tablettes et ordinateurs

##  Installation et utilisation

Aucune installation particulière n'est nécessaire.

### 1. Cloner le projet

```bash
git clone https://github.com/sergio526Hal/madaeyes.git
```

### 2. Entrer dans le dossier

```bash
cd madaeyes
```

### 3. Lancer le projet

Ouvrir simplement :

```text
index.html
```

dans un navigateur web.

Vous pouvez également utiliser **Visual Studio Code** avec l'extension **Live Server** pour lancer le projet localement.
